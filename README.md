# Telegram File Gatekeeper Bot (Gatekeeper Branch)

A Telegram bot built with **Node.js** and the `node-telegram-bot-api v2` library, designed to share files through automatically generated links.

This branch (`gatekeeper`) introduces a powerful **Gatekeeper** system that turns your file links into a followers growth engine, requiring users to join a specific group or channel before they can access the files.

---

## Gatekeeper (Star Feature)

The **Gatekeeper** is the heart of this branch. It acts as a mandatory checkpoint for every user requesting a file:

- **Forced Subscription**: Users must join a designated Telegram group or channel before they can download anything.
- **One-Click Verification**: If a user isn't a member, the bot instantly prompts them to join and provides a handy verification button to check their membership again.
- **Seamless Experience**: Once they join, the bot automatically delivers the file without further hassle.

> **This turns your file-sharing bot into a powerful audience-building funnel.**

Note: If you do not need the Gatekeeper functionality (forcing users to join a group/channel), you can use the main branch of this project, which provides the core file-sharing features without the membership requirement.
Visit: https://github.com/antoinepdev/telegram-file-gatekeeper/tree/main

## ✨ Key Features

- **📈 Audience Growth**: Every download requires a follow, making it ideal for **growing your follower base**, building a community around your content and promoting content.
- **🗄️ Telegram Group as database**: Files are stored in your Telegram group (it is recommended to keep the group private so that only admins send content to the bot, preventing unnecessary link generation).
- **🔗 Permanent Links**: Each file uploaded to the Telegram group receives a unique and permanent link.
- **🌐 Universal Access**: Links can be shared with anyone, even if they are not members of the Telegram group.
- **🛡️ Enhanced Privacy**: Your Telegram group (where you store the files) will not interact with users; therefore, if any file has copyright issues, the bot will bear the consequences, not the entire group with all your files. (As this feature can encourage piracy, please use the bot wisely).
- **📊 Zero cost per file**: When a user requests a file, the bot merely forwards it, so it consumes practically no resources regardless of the file size.

## 🚀 How It Works

1. **Create a Telegram group** (preferably private) to serve as the file storage.
2. **Add the bot as an administrator** to the group, granting read and write permissions.
3. **Send files to the group** - the bot will automatically generate a unique link per file.
4. **Share links** with anyone.
5. **The Gatekeeper in action**:
   - When a user clicks a link, the bot checks if they are a member of your telegram group/channel.
   - If **not** a member, the bot sends a message asking them to join, along with a **"Verify Membership"** button.
   - Once the user joins and clicks the button, the bot confirms membership and delivers the file.
   - If they are already a member, the bot delivers the file immediately.

## ⚙️ Setup

### 1. Clone the Repository

```bash
git clone -b gatekeeper https://github.com/antoinepdev/telegram-file-gatekeeper.git
cd telegram-file-gatekeeper
```

### 2. Install Dependencies

```bash
bun install
```

### 3. Configure Environment Variables

Create a `.env` file in the project root with the following variables:

| Variable                      | Description                                                                     | How to Obtain                                                                                            |
| ----------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `BOT_TOKEN`                   | Bot authentication token                                                        | Generated by [@BotFather](https://t.me/BotFa)                                                            |
| `PRIVATE_GROUP_ID`            | ID of the group where files will be stored                                      | Obtain by adding [@RawDataBot](https://t.me/RawDataBot) to the group and copying the `"chat"."id"` value |
| `BOT_URL`                     | Public bot link (e.g., `https://t.me/YourBotName`)                              | Provided by @BotFather when creating the bot                                                             |
| `REQUIREMENT_ID`              | ID of the Telegram group/channel the user must join                             |                                                                                                          |
| `REQUIREMENT_TARGET`          | invitation link of your Telegram group/channel                                  | Configure on your group/channel settings                                                                 |
| `REQUIREMENT_KEYBOARD_PROMPT` | Prompt that the bot will send to the user to ask them to join the group/channel |

#### Example `.env` file:

```env
BOT_TOKEN=717jfjfngncn:AAFpl5chxhdvwk4n1yKpznjfafdmqZ3chfjfr
PRIVATE_GROUP_ID=-10024749023698
BOT_URL=https://t.me/peliss_bot
REQUIREMENT_ID=-114312451545
REQUIREMENT_TARGET=https://t.me/adgroupinvitationlinkexample
REQUIREMENT_KEYBOARD_PROMPT='You need to join the following channels to access the file.'
```

### 4. Start the Bot

```bash
bun prod
```

If configured correctly, you will see the message `"Running..."` in the console.
